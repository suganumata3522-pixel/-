# タネポコ・ラッシュ

小さな探検隊長が「タネポコ」を投げて、まん中のレーンから攻めてくるムシの大群をくい止めるブラウザゲームです。
両サイドのブロックや台座に書かれた数字の回数だけタネポコを当てると、アイテムや仲間が手に入ります。

`index.html` 1 ファイルだけで動きます（ビルド不要）。ブラウザで開けばそのまま遊べます。

## 遊び方

| 操作 | スマホ | パソコン |
| --- | --- | --- |
| 隊長を左右に動かす | 画面を左右にドラッグ | ← → キー（A / D でも可） |
| 一時停止 | 右上の一時停止ボタン | Esc / P キー |

- タネポコは自動で投げます。隊長がいるレーンに向かって飛んでいきます。
- **まん中のレーン**：ムシに当たったタネポコはしがみついて攻撃し、倒すと隊長のもとへ走って戻ってきます。
  ムシが白い点線まで来るとライフ（ハート）が 1 減ります。ボスに突破されると一発アウトです。
- **左右のレーン**：数字の回数だけ当てると壊れて、ごほうびが出ます。
  - `+1` `+5` などのブロック … タネポコの仲間が増える（数字が 2 以上のブロックは、上の白い丸の数字が残り回数）
  - 台座 … 上に浮かんでいるアイテムや仲間がもらえる（台座の数字が必要な回数）
- 投げられるのは隊長のそばにいるタネポコだけです。バッジの「6 / 11」は「いま投げられる数 / 全部の数」です。
- 敵を倒しつつ、すきを見てサイドで強くなるのがコツです。

### アイテムと仲間

| 名前 | 効果 |
| --- | --- |
| なげる数 +1 | いちどに投げる数が増える（最大 3） |
| スピードてぶくろ | 投げる速さアップ |
| パワーひりょう | こうげき力アップ |
| ハート | ライフ +1（最大 5） |
| ほのおのタネ | 当たったムシのまわりも燃やす |
| カミナリのタネ | いなずまが近くのムシに連鎖する |
| ドッシン岩 | まん中のレーンを転がってムシをまとめてつぶす |
| テントウ騎士（仲間） | まん中のレーンの入口でムシをせき止めて戦う |
| ハチ弓兵（仲間） | 隊長のそばを飛びながら針でムシをうつ（最大 3 匹） |

ステージは 1 つずつ独立しています（毎回タネポコ 6 匹＋ステージに応じたボーナスからスタート）。
クリアしたステージはブラウザに保存され、タイトル画面の「つづきから」で続きのステージから遊べます。

## ファイル構成

- `index.html` … ゲーム本体（HTML / CSS / JavaScript をすべて含む）

外部への依存は Google Fonts（M PLUS Rounded 1c / Mochiy Pop One）だけです。オフラインでも代替フォントで動きます。
効果音と BGM は Web Audio API でその場で合成しているので、音声ファイルはありません。

## 調整したいとき

`index.html` の `<script>` 内で、次の関数・定数を変えると難易度やバランスを調整できます。

- `buildWaves(n)` … ステージ n のムシの出現タイミング・数
- `ENEMY` … ムシの体力・速さ
- `buildLanes(n)` … 左右レーンのブロック・台座の並び、必要回数、ごほうび
- `applyItem(id)` … アイテムの効果量
- `BASE_RATE` / `IMPACT` / `DPS` / `START_SQUAD` / `THROW_RANGE` … 投げる速さ・攻撃力・初期数・射程

キャラクター・敵・アイテムはすべてオリジナルのデザインで、Canvas に直接描いています（画像ファイルなし）。
