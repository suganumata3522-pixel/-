# はっぱ連鎖

はっぱっこ（葉っぱの生えた小さな子たち）を同じ色で4ひきつなげて消す、落ちものパズルです。
ルールは「ぷよぷよ通」に準拠しています（6列 × 13段、13段目はつながらない、3列目12段目が埋まると終了）。

- `index.html` … ゲーム本体（1ファイル完結。ブラウザで開けば遊べます）
- `shorts_19chain.mp4` … YouTube ショート用の縦動画（1080×1920 / 60fps / 理論値19連鎖 → 全消し）
- `boards.json` … 収録している19連鎖ボード（すべてシミュレーションで検証済み）

## 操作

| キー | 操作 |
| --- | --- |
| ← → | 移動 |
| ↑ / X | 右回転 |
| Z | 左回転 |
| ↓ | 高速落下 |
| P / Esc | 一時停止 |

スマホでは画面下のボタンで操作できます。「19れんさを はっかする」を押すと理論値19連鎖のボードが読み込まれ、
最初のペアを3列目にそのまま落とすと19連鎖が始まります。

## 作り直し方

```sh
node tools/gen19.js 19 <seed>   # 19連鎖ボードを逆算探索（出力を tools/gen_out_*.txt に保存すると build に取り込まれる）
node tools/build.js             # src/ を1ファイルにまとめて index.html / artifact.html / boards.json を生成
node video/render.js 0 shorts_19chain.mp4   # 動画を書き出し（Playwright の Chromium と ffmpeg を使用）
```

`tools/build.js` は、各ボードが「19回とも4ひきずつ消えて全消し」「発火前は消える組がない」ことを確かめてから取り込みます。

キャラクター・効果音・BGM はすべてコードで生成したオリジナルです。
