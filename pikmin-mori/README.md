# あつまれ ピクミンの森

あつまれ どうぶつの森の島づくりを、オリマーとピクミンでやってみるファンメイドゲームです。
YouTube ショート用の **縦長 1080×1920** 画面で、見所をまとめた動画を自動で作れます。

## ゲームの流れ

1. オリマーのドルフィン号が島の空港（砂浜）に着陸、オニヨンも降りてくる
2. 地面のピクミンを **引っこ抜いて** 仲間にする
3. ピクミンを **投げて** はたらかせる
   - 木を切る → 木材 / 岩をたたく → 石 / 雑草をぬく
   - 果物の木・ペレット草 → オニヨンに運ぶとタネが出て **ピクミンが増える**
   - できた資材はみんなで「えっほえっほ」と本部へ運ぶ
4. 資材がそろうと目標の建物の **工事が始まる** → 工事現場にピクミンを投げて建てる
   - ピクミンの家（住民ピクミンが引っ越してくる）×4 / 橋 / ルーイの商店 / 博物館 / 噴水広場
   - 建物が増えるほど **島評価 ★** がアップ、道も自動で敷かれる
5. 島評価 ★5 で夜の **花火大会** → 完成！

時計はあつ森のように進み、夕方・夜になると家の窓や街灯が光ります。

## 遊びかた

```bash
cd pikmin-mori
python3 -m http.server 8000   # → http://localhost:8000/
```

| 操作 | タップ / マウス | キーボード |
| --- | --- | --- |
| オリマーの移動 | 地面をタップ | WASD / 矢印 |
| ピクミンを引っこ抜く | 芽をタップ | Z |
| ピクミンを投げる | 木・岩・草・果物・工事現場をタップ（長押しで連続） | Space |
| ふえ（よびもどす） | 「ふえ」ボタン | X |
| ズーム切りかえ | 「ズーム」ボタン | C |
| オートプレイ | 「オート」ボタン | Tab |
| 音を消す | — | M |

## 見所動画の作りかた

オートプレイが島を一から完成させる様子を録画します。引っこ抜き・木が倒れる・建物の完成・花火などの
**見所は等速＋字幕**、それ以外は **▶▶ はやおくり（10倍速）** で、約 1 分 20 秒にまとまります。
乱数を使わない固定ステップなので、何回作っても同じ動画になります。

```bash
# 必要なもの: Node.js, Playwright (Chromium), ffmpeg
node tools/record.js out/pikmin-mori-shorts.mp4 --both --crf 18
#  → out/pikmin-mori-shorts.mp4      BGMなし（効果音・ジングルあり）
#  → out/pikmin-mori-shorts-bgm.mp4  BGMあり
```

- `node tools/sim.js` … 描画なしで通しプレイ（建物の完成時刻などを表示）
- `node tools/shots.js <フォルダ> <動画フレーム番号...>` … 好きな場面の静止画
- `node tools/build-artifact.js out.html` … 1ファイルにまとめたHTML

## ファイル構成

```
index.html        画面とスタイル
js/world.js       島の地形・川・建設予定地・木や岩の配置
js/game.js        ゲーム本体（オリマー・ピクミン・資材運び・建設・時計・島評価・見所イベント）
js/bot.js         オートプレイ
js/art.js         すべての描画（島・キャラクター・建物・夜の明かり・UI）
js/audio.js       チップチューン・シンセ（BGM / 効果音、すべてオリジナル曲）
js/main.js        入力・ゲームループ・録画用 API（見所は等速、それ以外は早送り）
fonts/            M PLUS Rounded 1c（SIL OFL）を使用文字だけに絞ったもの
```
