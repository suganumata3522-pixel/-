# どんぐりっこの森

どんぐりの妖精「どんぐりっこ」を集めて、森のおとしものをおうち(大きな切り株)へ運び、
森をにぎやかにしていくオリジナルのほのぼのゲームです。
遊んでいるあいだの**見所は自動でクリップ**され、**YouTubeショート用の縦型(9:16)動画**にしてそのまま投稿できます。

- HTML / CSS / JavaScript だけで動きます(インストール・ビルド不要、画像ファイルもなし)
- スマホ(タッチ)とPC(キーボード+マウス)の両方に対応
- 進み具合はブラウザに自動保存されます

> キャラクター・名前・絵・音はすべてこのゲームのために作ったオリジナルです。

## あそびかた

| やること | スマホ | PC |
|---|---|---|
| あるく | 画面をスワイプ(その場にスティックが出ます) | `W` `A` `S` `D` / 矢印キー |
| なげる | 投げたい場所をタップ(長おしで連続) | クリック(おしっぱなしで連続) |
| おいで!(集合) | 右下の「おいで!」 | `スペース` |
| 録画 開始/停止 | 「●録画」 | `R` |
| いまの見所をクリップ | 「✨見所」 | `H` |

1. 地面からのぞく**芽**に近づくと、どんぐりっこが仲間になってついてきます。
2. おとしもの(どんぐり・いちご・りんご…)に**投げる**と、みんなでおうちへ運びます。
   上に出る数字は「いまの力 / 必要な力」。運ぶと**もりコイン**と**新しい芽**がもらえます。
3. 橋の前の**丸太**は10ぴきくらいでどかせます。北の深い森には、すいか・きらきら石・**金のりんご**(20ぴき必要)も。
4. 1日は約4分。夕方・夜・朝があり、夜は**ながれぼし**、雨のあとは**にじ**が見られることも。
5. **おみせ**で花だん・ランタン・ふんすい・どんぐりの塔などを買って、森をかざれます。

どんぐりっこの種類: **ちゃいろ**(ふつう)、**こけ**(足がはやい)、**きん**(力が2倍・光る)。

## 見所をYouTubeショートにする

### 1. 見所をためる
- **自動クリップ**: 大物を運んだ・はじめてのアイテム・ながれぼし・にじ・丸太をどかした・仲間が10/25/50/100ぴき、などの瞬間に、
  **その直前の数秒をさかのぼって**自動で保存します(画面右の「🎬ショート」に数が出ます)。
- **✨見所ボタン**: 「いまのよかった!」と思ったら押すと、直前の数秒をクリップにします。
- **●録画ボタン**: 好きな場面を最大60秒(せっていで30秒/3分に変更可)録画します。

### 2. ショート動画をつくる
「🎬ショート」→ つなげたいクリップにチェック → **「ショート動画をつくる」**。
オープニング(タイトル)、テロップ、エンディング(きょうの成績)つきの **720×1280 の縦型動画**ができます。
60秒以内がおすすめ、3分(ショートの上限)をこえるとつくれません。

※ 動画づくりは実際の時間ぶん再生しながら行うので、終わるまでその画面をひらいたままにしてください。

### 3. 投稿する
| 方法 | 手順 |
|---|---|
| **スマホ(おすすめ)** | 「📱共有」→ YouTube を選ぶ。出てこないときは「💾動画を保存」→ YouTubeアプリの「＋」→「ショート」→ 左下のアルバムから選ぶ |
| **PC** | 「💾動画を保存」→「▶YouTubeをひらいて投稿」(タイトルと説明がコピーされます)→ 保存した動画を選ぶ。縦長で3分以内なら自動でショートになります |
| **直接アップロード(上級者向け)** | 下の「YouTubeに直接アップロードする準備」を参照 |

タイトルには自動で `#Shorts`、説明にはハッシュタグが入ります(編集できます)。

## 起動のしかた

### いちばんかんたん
`donguri-mori/index.html` をブラウザ(Chrome / Edge / Safari の最新版がおすすめ)で開くだけで遊べ、録画・動画づくりもできます。

### ローカルサーバーで開く(YouTube直接アップロードを使うとき)
Googleのログインは `file://` では動かないので、かんたんなサーバーで開きます。

```bash
cd donguri-mori
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

### スマホで遊ぶ(ネットに公開する)
静的ファイルだけなので、GitHub Pages・Netlify・Cloudflare Pages などに `donguri-mori` フォルダの中身を置けば公開できます。
このリポジトリの GitHub Pages は「構造設計ナビ」用なので、ゲーム用には**新しいリポジトリを作って中身をコピー**し、
Settings → Pages → Branch を `main` / `(root)` にするのがかんたんです。

## YouTubeに直接アップロードする準備(任意・上級者向け)

ふつうは「保存 → YouTubeアプリ/Studioで投稿」で十分です。ゲームから直接アップロードしたい場合だけ、以下を行ってください。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を有効化
3. 「OAuth同意画面」を作成(外部・テスト中でOK)し、**テストユーザー**に自分のGoogleアカウントを追加
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は **ウェブアプリケーション**
5. 「承認済みのJavaScript生成元」に、ゲームを開くURLのオリジンを追加
   (例: `http://localhost:8000`、公開したなら `https://ユーザー名.github.io`)
6. できたクライアントID(`xxxx.apps.googleusercontent.com`)を、ゲームの「⚙せってい」→「Google OAuth クライアントID」に貼りつけ
7. ショート動画をつくったあと「⬆YouTubeに直接アップロード」→「Googleでログインしてアップロード」

注意:
- **審査(監査)を受けていないGoogle Cloudプロジェクトからアップロードした動画は、YouTubeの決まりで「非公開」に固定されます。**
  公開したいショートは、保存してからYouTubeアプリやStudioで投稿してください。
- YouTube Data API には1日の利用上限(割り当て)があり、アップロードは1回で約1600ユニット使います(初期の上限は1日10,000ユニット)。
- クライアントIDは公開されても問題ない値ですが、**クライアントシークレットは使いません・貼らないでください。**

## ファイル構成

```
donguri-mori/
├── index.html        画面とメニュー
├── css/style.css     見た目
├── assets/icon.svg   アイコン
└── js/
    ├── util.js       共通の道具・ゲームの数値(アイテムの重さ・値段など)
    ├── audio.js      効果音とBGM(Web Audioで合成。録画にも同じ音が入る)
    ├── sprites.js    キャラ・木・アイテムの絵(Canvasで描画)
    ├── world.js      森のマップ・当たり判定・橋の道案内
    ├── game.js       ゲーム本体(どんぐりっこ・運ぶ・1日の流れ・見所イベント)
    ├── render.js     描画(このCanvasがそのまま動画になる)
    ├── recorder.js   録画と、見所のさかのぼりクリップ
    ├── studio.js     ショート動画スタジオ(つなぐ・テロップ・保存・共有)
    ├── youtube.js    YouTube Data API での直接アップロード
    └── main.js       操作・HUD・メニューのつなぎこみ
```

数値の調整は `js/util.js` の `DF.ITEMS`(アイテム)、`DF.DECOS`(かざり)、`DF.C`(1日の長さ・最大数など)を変えるだけでできます。

## しくみメモ

- ゲーム画面は 720×1280 の Canvas に描いていて、`canvas.captureStream()` と `MediaRecorder` でそのまま録画します。
  ボタンなどのHTML部分は録画に入りません(見所のバナーはCanvasに描くので入ります)。
- 自動クリップは、レコーダーを交代で回し続けて「いつでも直前7秒以上の録画がある」状態を保ち、見所が起きたら3秒後に切り出します。
  2台同時に動くのは交代のときだけなので、重くなりにくくしています。
- 書き出し形式は MP4(H.264)を優先し、使えないブラウザ(Firefoxなど)では WebM になります。どちらもYouTubeにアップロードできます。
- クリップはメモリ上だけに置いているので、ページを閉じると消えます。気に入ったものはその場で保存してください。
