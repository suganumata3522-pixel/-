# はっぱライン

4ひき組で落ちてくる はっぱっこを並べて、横一列そろうと収穫（消える）落ちものパズルです。
キャラクター・効果音・BGM は「はっぱ連鎖」（`../sprout-chain`）と共通のコードを使っています。

- `index.html` … ゲーム本体（1ファイル完結）
- `shorts_4lines.mp4` … YouTube ショート用の縦動画（1080×1920 / 60fps）。16段の畑を4段消し×4回で全消し
- `stack.json` … 4段消しチャレンジの畑（28組・各形4回ずつ。1組ずつまっすぐ落として作れることを検証済み）

## ルール

横8列 × 縦18段（上に出現用の2段）。一度に消せるのは最大4段（たて棒だけが4段の高さを持つため）。
続けて消すと「れんぞく」ボーナス、盤面を空にすると全消しボーナス。

## 操作

| キー | 操作 |
| --- | --- |
| ← → | 移動 |
| ↑ / X | 右回転 |
| Z | 左回転 |
| ↓ | 速く落とす |
| Space | 一気に落とす |
| P / Esc | 一時停止 |

## 作り直し方

```sh
node tools/genstack.js 7 > stack.json   # チャレンジ用の畑を生成・検証
node tools/build.js                     # index.html / artifact.html を生成
node tools/test_game.js desk            # ブラウザでチャレンジを通しプレイして確認
node video/render.js shorts_4lines.mp4  # 動画を書き出し
```
