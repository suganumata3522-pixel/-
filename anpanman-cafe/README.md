# はたらく！アンパンマン工場カフェ（ファンメイド非公式ゲーム）

「はたらく！ワドルディカフェ」風のタイムマネジメントゲームです。
ジャムおじさんになって、アンパンマン工場に新しくできたカフェでパンを売ります。

`index.html` をブラウザで開くだけで遊べます（画像ファイル不要・スマホ縦向き推奨）。

## ルール

- お客さんの吹き出しと同じパンを、下のショーケースから **タップ** して渡す
- お客さんを待たせると、上の **おきゃくさま まんぞくど** ゲージが少しずつ減る
  - 待ち時間が長いほど早く減る（2.5秒・5秒で段階アップ、5秒でぷんぷん顔）
  - ちがうパンを押すとゲージ −6
  - 注文をそろえるとゲージ回復（すばやく渡すとボーナス）
- **50秒** 乗り切ればクリア。ゲージが 0 になるとゲームオーバー
- **のこり20秒からランチタイム**：ゲージの減りが約2.2倍、お客さんが次々来る、注文の出し方が増える
  - 2〜3品の注文／「×2」の個数指定
  - シルエット（黒い影）だけの注文
  - 文字だけの注文
- 3回以上連続で成功するとコンボボーナス。売上で ★1〜★3 の評価

## 操作

- タップ／クリック
- キーボード：`1`〜`8` または `Q W E R / A S D F` でパン、`Space` でスタート、`M` で消音
- `index.html?demo=1`（公開ページでは URL の末尾に `#demo`）で自動プレイのデモ

## YouTubeショート用動画

- `video/anpanman-cafe-shorts.mp4` … 1080×1920（9:16）・60fps・約59.7秒・音声つき（−14 LUFS）
- `video/cover.jpg` … ランチタイム中の1コマ（サムネイル候補）

動画は自動プレイ（シード固定）を1フレームずつ描画して書き出しています。
BGM・効果音はゲームと同じ音源をそのままオフライン合成しています（オリジナル曲）。

作り直す場合（Node.js + Playwright + ffmpeg が必要）：

```
node record.js                     # video/anpanman-cafe-shorts.mp4 を再生成
node preview.js shots 23 1,20,40   # 指定秒のスクリーンショット（確認用）
```

展開を変えたいときは `record-config.js` のシードや自動プレイの速さを変更します。
難易度は `index.html` の `TUNE`（ゲージの減り方・回復量・来店間隔・★の基準）で調整できます。
