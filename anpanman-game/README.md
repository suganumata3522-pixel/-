# スーパーアンパンマン 〜かびるんるん だいさくせん〜

スーパーマリオブラザーズ風の横スクロールアクションを、アンパンマンの世界でつくったファンメイドゲームです。
YouTube ショート用に **縦長 1080×1920** の画面で、下半分にコントローラーが表示されます。

- 主人公：アンパンマン（Ⓐジャンプ／Ⓑアンパンチ）
- ザコ敵：かびるんるん（緑＝ふみつけ、紫＝ふむと丸まってけれる、羽つき＝ぴょんぴょん）
- ボス：バイキンマン（バイキンUFO、パンチ落とし＋バイキン爆弾）
- 「？」ブロックから飛んでくる **あたらしい顔** で「げんき100ばい！」
- 全3ステージ：1-1 あおぞら草原 / 1-2 ゆうやけの森 / 1-3 バイキン城（ボス戦）

キャラクターはすべて canvas のコードで描いています（画像ファイルなし）。BGM・効果音はすべてオリジナル曲で、ブラウザ内のシンセで生成しています。

## 遊びかた

ローカルサーバーで `index.html` を開きます（フォント読み込みのため）。

```bash
cd anpanman-game
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| いどう | ← → / A D | 十字キー |
| ジャンプ（長押しで高く） | Z / Space | A ボタン |
| アンパンチ | X | B ボタン |
| スタート | Enter | START（またはタイトル画面をタップ） |
| オートプレイ ON/OFF | Tab | SELECT |
| 音を消す | M | — |

## 動画の作りかた

オートプレイ（`js/bot.js`）がゲームをクリアする様子を 1 フレームずつ描画して、60fps の MP4（音声つき）にします。
ゲームは乱数を使わない固定ステップなので、何回作っても同じ動画になります。

```bash
# 必要なもの: Node.js, Playwright (Chromium), ffmpeg
node tools/record.js out/anpanman-shorts.mp4 --crf 18
```

- 出力：1080×1920 / 60fps / H.264 + AAC、約 2 分 52 秒（YouTube ショートの上限 3 分以内）
- `node tools/sim.js` で描画なしの通しプレイを数秒で確認できます（クリア時間・被ダメージ数など）
- `node tools/shots.js <出力フォルダ> <フレーム番号...>` で好きな場面の静止画を保存できます

## ファイル構成

```
index.html          画面とスタイル
js/game.js          ゲーム本体（物理・当たり判定・敵・ボス・進行）
js/levels.js        ステージの地形と敵の配置
js/bot.js           オートプレイ（物理シミュレーションで先読みして操作）
js/art.js           すべての描画（キャラクター・背景・HUD・コントローラー）
js/audio.js         チップチューン・シンセ（BGM / 効果音 / 動画用ミックス）
js/main.js          入力・ゲームループ・録画用 API
fonts/              M PLUS Rounded 1c（SIL OFL）を使用文字だけに絞ったもの
tools/              録画・静止画・シミュレーション・1ファイル化のスクリプト
```

画面に新しい文字を追加したら `python3 tools/fetch-fonts.py` でフォントを作り直してください。
