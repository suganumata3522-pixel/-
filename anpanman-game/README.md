# スーパーアンパンマン 〜ジャムおじさん姫を たすけだせ!〜

スーパーマリオブラザーズ風の横スクロールアクションを、アンパンマンの世界でつくったファンメイドゲームです。
YouTube ショート用に **縦長 1080×1920** の画面で、下半分にコントローラーが表示されます。

- 主人公：アンパンマン（Ⓐジャンプ／Ⓑアンパンチ／↑で **そらをとぶ**）
- ザコ敵：かびるんるん（緑＝ふみつけ、紫＝ふむと丸まってけれる、羽つき＝ぴょんぴょん）
- ボス：バイキンマン（バイキンUFO、パンチ落とし＋バイキン爆弾）。地上からは3回当てて倒すが、**とびながらのアンパンチなら一撃**で「バイバイキン〜!」とふっとぶ
- 「？」ブロックから飛んでくる **あたらしい顔** で「げんき100ばい！」
- ストーリー：ピーチ姫の格好をした **ジャムおじさん姫** がバイキンマンにさらわれる → バイキン城の奥のオリにとらわれている → バイキンマンを倒すとオリが開いて「ありがとう アンパンマン!」
- 全3ステージ：1-1 あおぞら草原 / 1-2 ゆうやけの森 / 1-3 バイキン城（ボス戦）
- **EXステージ「じごくの バイキン城」（鬼ムズ）**：そらは とべない・ノーミス前提の 6 つの関門
  1. 溶岩の飛び石（高さバラバラの1マス柱＋すきまから飛び出すマグマだま）
  2. ファイアバー回廊（天井の低い通路で回る3本のファイアバー、まん中は両腕）
  3. ストンプ渡り（溶岩の上にうかぶ羽かびるんるんを ふみつけて渡る。上ではファイアバーが回る）
  4. マグマだま地帯（1マス柱とマグマだま5つ）
  5. トゲトンネル（天井トゲ＋床トゲ。ジャンプは低く短く）
  6. ラストジャンプ（助走して高い柱へ → 低い柱へ → ゴール）
- **EX-2ステージ「しんえんの とりで」（超鬼ムズ・むずかしさ げんかい とっぱ）**：オリジナルキャラ **ニンジャぎつね コン** が主人公の、さらに難しい 8 つの関門（敵はオニとコウモリ）
  1. きえる足場（溶岩の上で、波のように順番に出たり消えたりする足場）
  2. クロスファイアバー（頭の高さで回る 4 本腕のファイアバー。腕が通りすぎた直後にすべりこむ）
  3. トゲプレス回廊（天井からトゲつきのプレスが順番にドスン。すきまで待って通りぬける）
  4. てっきゅう砲台（足もと・胸・頭の高さに飛んでくる鉄球をジャンプでかわしながら砲台をのりこえる）
  5. コウモリ渡り（27 マスの溶岩を、ぐるぐる飛ぶコウモリを ふみつけて渡る。真上には 4 本腕のファイアバー）
  6. トゲトンネル改（天井トゲが低く、A ボタンを 1〜2 フレームだけ押す小ジャンプしか通れない。2 マスの床トゲは走りながら）
  7. せまりくるトゲかべ（通路に入るとトゲのかべが追いかけてくる。止まったらおしまい）
  8. ラストアタック（消える足場とマグマだまをこえてゴール）

キャラクターはすべて canvas のコードで描いています（画像ファイルなし）。BGM・効果音はすべてオリジナル曲で、ブラウザ内のシンセで生成しています。

## 遊びかた

ローカルサーバーで `index.html` を開きます（フォント読み込みのため）。

```bash
cd anpanman-game
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| いどう | ← → / A D | 十字キー |
| ジャンプ（長押しで高く） | Z / Space | A ボタン |
| アンパンチ | X | B ボタン |
| そらをとぶ（とんだら上下左右に移動・地面にふれると着地） | ↑ / W | 十字キー上 |
| スタート | Enter | START（またはタイトル画面をタップ） |
| オートプレイ ON/OFF | Tab | SELECT |
| 音を消す | M | — |

## 動画の作りかた

オートプレイ（`js/bot.js`）がゲームをクリアする様子を 1 フレームずつ描画して、60fps の MP4（音声つき）にします。
ゲームは乱数を使わない固定ステップなので、何回作っても同じ動画になります。オートプレイは 2 種類あります。

| `--bot` | 内容 | 長さ |
| --- | --- | --- |
| `fly`（標準） | 空を飛んで一直線にゴール。バイキンマンは空中アンパンチ一発でふっとばす | 約 1 分 41 秒 |
| `ground` | 走ってジャンプ、かびるんるんをふんだりパンチしたり、ボスは3回当てて倒す | 約 2 分 58 秒 |
| `tas` | EX・EX-2 ステージ専用。`tools/tas.js` が探した入力をそのまま再生するノーミスクリア（`--stage 4` は EX：クリアタイム 38 秒、`--stage 5` は EX-2：クリアタイム 42 秒） | 約 55 秒 / 約 60 秒 |

```bash
# 必要なもの: Node.js, Playwright (Chromium), ffmpeg
node tools/record.js out/anpanman-hime-shorts-nobgm.mp4 --bot fly --no-bgm --crf 18
node tools/record.js out/anpanman-shorts.mp4 --bot ground --crf 18
```

- 出力：1080×1920 / 60fps / H.264 + AAC（YouTube ショートの上限 3 分以内）
- `--stage 3` をつけると、そのステージだけ（WORLD の紹介画面からクリアまで）の動画になります。例：`node tools/record.js out/castle.mp4 --bot ground --stage 3 --no-bgm`（`--story` を足すと、最初にジャムおじさん姫がさらわれるオープニングが入ります）
- `--no-bgm` をつけると BGM（くり返し流れる曲）だけを消した動画になります。コイン・敵・パンチなどの効果音と、ステージ開始・クリア・勝利のジングルは残ります
- `node tools/sim.js 14000 fly`（または `ground`）で描画なしの通しプレイを数秒で確認できます
- EX ステージのクリア動画：`node tools/record.js out/anpanman-ex-tas-nobgm.mp4 --bot tas --stage 4 --no-bgm --crf 18`（ブラウザでは `index.html?stage=4&bot=tas` を開き、スタート前に SELECT でオートプレイを ON）
- EX-2 ステージのクリア動画：`node tools/record.js out/kon-ex2-tas-nobgm.mp4 --bot tas --stage 5 --no-bgm --crf 18`（ブラウザでは `index.html?stage=5&bot=tas`）
- ブラウザで遊ぶときのオートプレイは `fly`。`index.html?bot=ground` で地上版になります
- `node tools/shots.js <出力フォルダ> <フレーム番号...>` で好きな場面の静止画を保存できます

### EX ステージの攻略ルートさがし（tools/tas.js）

`node tools/tas.js 4 --width 600 --per-cell 10 --seg 2` で、EX ステージを **1 回もダメージを受けずに** クリアする入力を探して `js/tas-ex.js` に書き出します。

- ゲーム本体（`js/game.js`）をそのまま使って 1 フレームずつ動かす「ビームサーチ」です。2〜3 フレームごとに 8 通りの入力（左右・ジャンプ長押し・パンチ）をためし、ダメージを受けた・落ちた候補はすべて捨てます
- 同じ状態の候補はまとめ、「どこにいるか × 動き（走り/止まり/上昇/落下）」ごとに数を制限して、タイミング違いの候補を残します（ファイアバーやマグマだまの周期に合わせるため）
- ボタンの押し替えやパンチに小さなコストをつけて、人が操作しているように見える入力を優先します
- ファイアバーとマグマだまはステージ開始からのフレーム数だけで動くので、見つけた入力は動画でも必ず同じ結果になります（最後に新しいゲームで再生して確認します）
- ステージを変えて解けなくなったら `--hist 1`（候補の分布）や `--dump <深さ>`（先頭の候補の状態）で、どこで止まったかを調べられます
- EX-2 は `node tools/tas.js 5 ...` で `js/tas-ex2.js` に書き出します。長いステージは関門ごとに解くと速いです：
  - `--stall 250` … 先頭が 250 区間すすまなかったらあきらめる
  - `--save-front 途中.js` … 解けなかったとき、いちばん先まで進んだ入力を保存する
  - `--prefix 途中.js --until 157` … 保存した入力で 157 マス目まで進めてから、続きだけを探す（それより前の地形を変えていなければ有効）
- 入力の種類には「A を 1 フレームだけ押す」小ジャンプもあります（トゲトンネル改用）

## ファイル構成

```
index.html          画面とスタイル
js/game.js          ゲーム本体（物理・当たり判定・敵・ボス・進行）
js/levels.js        ステージの地形と敵の配置
js/bot.js           オートプレイ（物理シミュレーションで先読みして操作）と、入力リストを再生する TasBot
js/tas-ex.js        EX ステージのノーミス入力リスト（tools/tas.js が生成）
js/tas-ex2.js       EX-2 ステージのノーミス入力リスト（tools/tas.js が生成）
js/art.js           すべての描画（キャラクター・背景・HUD・コントローラー）
js/audio.js         チップチューン・シンセ（BGM / 効果音 / 動画用ミックス）
js/main.js          入力・ゲームループ・録画用 API
fonts/              M PLUS Rounded 1c（SIL OFL）を使用文字だけに絞ったもの
tools/              録画・静止画・シミュレーション・1ファイル化のスクリプト
```

画面に新しい文字を追加したら `python3 tools/fetch-fonts.py` でフォントを作り直してください。
