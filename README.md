# 構造設計ナビ

建築の構造設計・構造力学をわかりやすく解説する学習サイトです。
公開URL: https://www.kouzou-navi.com

サイト本体のファイルは [`kouzou-site/`](kouzou-site/) フォルダにあります。
HTML / CSS / JavaScript のみの静的サイトで、GitHub Pages で公開しています。

詳しい構成・編集・記事追加・運営の手順は
[`kouzou-site/運営マニュアル.md`](kouzou-site/運営マニュアル.md) を参照してください。

## ツール

- [`tools/weibull-annual-max-temp/`](tools/weibull-annual-max-temp/) —
  気象庁の年最高気温から、ワイブル分布（第III種極値分布）で
  **再現期間100年の年最高外気温度** を求める Excel ブック。
