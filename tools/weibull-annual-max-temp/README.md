# 年最高外気温度の極値統計解析（再現期間100年 / ワイブル分布）

気象庁が公開している **年最高気温** の観測記録に極値統計をあてはめ、
**再現期間 100 年に対する年最高外気温度** を求める Excel ブックです。

- 成果物: [`年最高外気温_ワイブル極値解析.xlsx`](年最高外気温_ワイブル極値解析.xlsx)
- 生成スクリプト: [`generate_workbook.py`](generate_workbook.py)

空調負荷計算・設備機器の耐熱設計・屋外構造物の温度応力検討などで用いる
設計用外気温度の設定を想定しています。

## シート構成

| シート | 内容 |
|---|---|
| 使い方 | 目的・手順・計算式・注意事項 |
| データ入力 | **年** と **年最高気温(℃)** を貼り付ける（黄色いセルが入力欄、最大200年分）。経年変化グラフと回帰トレンドを自動表示 |
| 極値統計計算 | 順位統計・確率プロット・ω のグリッド探索・分布母数の推定（自動計算、通常は触らない） |
| 結果 | 再現期間表（T=2〜200年）、確率プロット、再現期間曲線 |
| サンプルデータ | 動作確認用のダミー標本の控え |

計算はすべて **Excel の数式** として書き込んであります。
データを入れ替えれば自動で再計算され、マクロ（VBA）は使っていません。

## 計算方法

1. 標本を降順に並べて順位 `m` を付ける（`m=1` が最大値）
2. 非超過確率をワイブルのプロッティング・ポジションで与える

   ```
   F = 1 − m/(n+1)      再現期間 T = 1/(1−F) = (n+1)/m
   ```

3. **ワイブル分布（第III種極値分布・上限型）** を最小二乗であてはめる

   ```
   F(x) = exp[ −((ω−x)/a)^k ]        x ≦ ω
   ln(−ln F) = k·ln(ω−x) − k·ln a    … ω を仮定すると直線になる
   ```

   上限母数 `ω` は 2 段階のグリッド探索（粗 → 細、各200点）で
   確率プロット上の相関係数 `r` が最大になる値を採用します。
   傾きが形状母数 `k`、切片から尺度母数 `a` が決まります。

4. 再現期間 `T` に対する値

   ```
   x(T) = ω − a·[ −ln(1 − 1/T) ]^(1/k)
   ```

5. 検証用に **グンベル分布（第I種極値分布）** も併記します
   （確率プロット最小二乗法と積率法の2通り、および Kite の式による近似95%信頼区間）

   ```
   F(x) = exp[ −exp(−(x−β)/α) ]      x(T) = β + α·[ −ln(−ln(1 − 1/T)) ]
   ```

気温には物理的な上限があると考えられるため、上に有界な第III種極値分布は
年最高気温に適した形をしています。ただし形状母数 `k` が大きく `ω` が標本最大値から
かけ離れて大きくなる場合、分布はグンベル分布（`k→∞` の極限）に漸近しています。
その判定は「極値統計計算」シートに自動表示され、「結果」シートにも転記されます。

## 気象庁データの取り方

**方法A: 過去の気象データ検索（年ごとの値）**
<https://www.data.jma.go.jp/obd/stats/etrn/index.php>
地点を選ぶ → 「年ごとの値を表示」 → 表の *最高気温(℃) / 最高* の列が年最高気温です。

**方法B: 過去の気象データ・ダウンロード（CSV）**
<https://www.data.jma.go.jp/risk/obsdl/index.php>
地点を選ぶ → 項目を選ぶ → *年別値* → *最高気温の最高* → CSV をダウンロード。
CSV は Shift_JIS です。Excel で開き、年と気温の 2 列を「データ入力」に貼り付けてください。
品質情報（均質番号・現象なし情報）の列が付くので、値が不完全な年は除いてください。

## 結果を使うときの注意

- **標本数**: `n≧30`、できれば `n≧50` を推奨。`n` が小さいまま100年を外挿すると誤差が大きくなります。
- **温暖化トレンド**: 極値統計は母集団が定常であることを前提にします。昇温トレンドがある地点で
  長期データをそのまま使うと過小評価になります。期間を直近30〜50年に絞る、または
  トレンド補正した値を入力してください（「データ入力」シートにトレンドを表示）。
- **観測所の移転・都市化**: 系列が不連続になります。気象庁の観測所メタデータで移転履歴を確認してください。
- **観測露場の気温**: 建物周辺の実効外気温は日射・輻射・排熱で数℃高くなることがあります。
  設計値には別途割増しを検討してください。
- 空調設計では TAC 温度など別の考え方もあります。用途に応じて使い分けてください。

## 検証

`generate_workbook.py` が書き込んだ数式は LibreOffice で全再計算して確認しています
（4,058 個の数式、エラー 0 件）。さらに次の 4 ケースでデータを差し替えて再計算し、
挙動を確かめました。

| ケース | 結果 |
|---|---|
| 上限のある母集団（逆ワイブル ω=42, a=8, k=3）から n=50 を発生 | 真の100年値 **40.27℃** に対し推定 **40.26℃**（グンベルは 42.19℃ と過大） |
| n=20 | 「△ n<30：信頼性は低い」を自動表示 |
| n=5 | 主結果を `―` にし「× n<10：極値解析には不足」を表示 |
| データ空 | 数式エラーなし、主結果 `―` |

分布母数は Python による独立実装と一致します
（ω=59.468、a=25.015、k=18.866、r=0.99703）。

## 出荷時のデータについて

「データ入力」シートには **動作確認用のダミー値**（グンベル分布に +0.02℃/年 の昇温トレンドを
与えて発生させた人工標本 75 年分）が入っています。**気象庁の実測値ではありません。**
設計に用いる前に必ず実データへ差し替えてください。
