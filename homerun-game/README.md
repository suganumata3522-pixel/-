# ジャムおじさんのホームラン競争

実況パワフルプロ野球のホームラン競争風のブラウザゲームです。
ピッチャーのバタコさんがアンパンマンの顔を投げ、バッターのジャムおじさんがフランスパンのバットで打ち返します。
画面は YouTube ショート向けの縦長(1080×1920)で、ゲーム内の録画ボタンでそのまま投稿用の動画を保存できます。

> 非公式のファンメイド作品です。キャラクターはすべてコードで描いたオリジナルの3Dモデルで、公式の画像や素材は使っていません。

## 遊び方

| 操作 | スマホ | PC |
| --- | --- | --- |
| 照準(ミートカーソル)を動かす | 画面を指でドラッグ | マウスを動かす / 矢印キー・WASD |
| 打つ | 指をはなす | クリック / スペース・Enter・Z |
| 強振 ⇔ ミート打ち | 上の「ミート/強振」ボタン | X キー |

- バタコさんは最速168km/hのストレートと、変化量MAX(7)のスライダー・SFF・シュートを投げます。セリフは吹き出しで出ます(声はなし)。振りかぶりで「アンパンマン!」、投げ始めに「新しい顔よ!」、ボールを離す瞬間に「それっ!」。
- 1回の勝負は5球。ホームランは 100点+飛距離、ヒットは10点です。一球も当たらないと、ジャムおじさんが帽子を叩きつけ、バットをへし折ってぶん投げます。
- **ミート打ち**はカーソルが大きく当てやすい、**強振**はカーソルが小さいかわりに飛びます。
- 照準の中心より少し下でボールをとらえると打球が上がり、ホームランになりやすくなります。
- 早めに振ると引っ張り(ライト方向)、遅れると流し打ち(レフト方向)。センターが一番深い(122m)です。
- 「オート」をオンにするとCPUが打ちます。最高記録はブラウザに保存されます。

## 9回裏の名場面

ツールバーの「9回裏の名場面」を押すと、9回裏2アウト満塁・一打サヨナラのピンチで、バタコさん(3-2でリード)がジャムおじさんと対戦する場面を再生します。ページのURLの最後に `#sayonara` を付けて開いても再生できます。

1. ボール(シュートが外れる)
2. 空振り(スライダー)
3. ボール(SFFがワンバウンド)
4. ファウル(168km/hのストレートをライト線へ)
5. ボール(高め)でフルカウント
6. SFFで空振り三振、ゲームセット

三振したジャムおじさんは帽子を地面に叩きつけ、フランスパンのバットをひざでへし折って、がっくりと崩れ落ちます。再生中は録画ボタンでそのまま縦動画にできます。

## 起動

`index.html` をブラウザで開くだけで動きます(ビルド不要)。
フォントは Google Fonts から読み込むので、オフラインだと代わりのフォントで表示されます。

GitHub Pages などに `homerun-game/` フォルダごと置けば、スマホからも遊べます。

## YouTube ショート用に録画する

1. 上の「● 録画」を押すと録画が始まり、ゲームが最初から始まります。
2. 結果発表を表示しきると自動で止まり、「動画を保存」で書き出せます(途中で止めることもできます)。
3. 保存される動画は 1080×1920 の縦動画です。Chrome / Edge / Safari では MP4、Firefox では WebM になります。どちらも YouTube にそのままアップできます。

- ボタンやダイアログは録画に映りません。ゲーム画面と効果音だけが入ります。
- 「実況」の読み上げ音声(ブラウザの音声合成)は録画に入りません。声も入れたい場合は、スマホの画面収録機能で撮るか、編集アプリでナレーションを足してください。
- ショートは3分まで投稿できます。1回の勝負はだいたい35〜50秒です。

## オートプレイの動画を書き出す(開発者向け)

ゲームを1コマずつ描画して、効果音つきの MP4 を作るスクリプトがあります。画面の実時間に左右されないので、コマ落ちのないきれいな動画になります。

```bash
# 必要: Node.js 18+, ffmpeg, Playwright (Chromium)
npm i -D playwright && npx playwright install chromium
node tools/record.mjs --seed 5 --out jam-homerun-short.mp4
```

| オプション | 内容 |
| --- | --- |
| `--seed N` | 試合展開の乱数(同じ値なら毎回同じ試合になります) |
| `--fps 30` | フレームレート(60 にすると滑らかですが書き出しに倍の時間がかかります) |
| `--balls 5` | 球数(ふつうは5球) |
| `--ai whiff` | ジャムおじさんが一球も当てられない動画にする(変化前のコースを追いかけ、タイミングもずれる) |
| `--scene sayonara` | 9回裏の名場面を書き出す(約54秒) |
| `--snap 2,5.5 --from 5` | 指定した秒数の静止画だけ保存(見た目の確認用) |

## サムネイルを作る

```bash
node tools/thumbnail.mjs --out thumbs                  # 4種類すべて
node tools/thumbnail.mjs --design hr-a,zero-a --out thumbs
```

ショート用のサムネイル(1080×1920 の JPEG、YouTube の上限 2MB 以内)を書き出します。ゲームと同じ3Dモデルを撮影して、背景のぼかし・白フチ・文字を重ねています。

| デザイン | 内容 |
| --- | --- |
| `hr-a` | 168km/hをかっ飛ばす!! (打った瞬間+飛んでいくアンパンマンの顔、5連発) |
| `hr-b` | フランスパンでホームラン!? (バンザイするジャムおじさん) |
| `zero-a` | 全5球 空振り… (がっくりするジャムおじさん) |
| `zero-b` | 168km/h バタコさん強すぎ… (新しい顔を持つバタコさん) |

文字や構図は `tools/thumbnail.js` の `designs` で変えられます。

## 調整できるところ

- URL パラメータ: `index.html?auto=1`(最初からオート)、`?balls=5`(球数)、`?seed=123`(試合展開を固定)、`?auto=1&ai=whiff`(オートが全部空振り)
- `js/game.js` の先頭: 投球の速さ `BALL_SLOW`、打球の再生速度 `FLIGHT_SPEED`、球種・球速・変化量 `PITCHES`
- バタコさんの吹き出しのセリフは `js/game.js` の `S.batakoSay` を設定している箇所で変えられます
- `js/core.js`: 飛距離(`HR.PHYS.k` と `HR.contactToLaunch`)、フェンスの距離 `HR.fenceR`、実況のセリフ `HR.LINES`、称号 `HR.RANKS`
- `js/models.js` の `makeJam()`: バットを普通の木製にしたいときはバットのテクスチャ部分を書き換えてください

## ファイル構成

```
index.html        画面とツールバー
js/core.js        定数・打球の物理・実況のセリフ
js/models.js      バタコさん・ジャムおじさん・アンパンマンの顔ボール(3Dモデル)
js/stadium.js     球場(芝・フェンス広告・観客・大型ビジョン)
js/audio.js       効果音(WebAudio で合成)と実況の読み上げ
js/hud.js         スコアボード・選手プレート・照準・ホームラン演出
js/game.js        ゲーム進行・打撃判定・カメラ・入力・録画
tools/record.mjs  オートプレイ動画の書き出し
tools/thumbnail.* ショート用サムネイルの書き出し
tools/browser.mjs 上の2つで使うヘッドレス Chromium の準備
vendor/three.min.js  Three.js r160 (MIT License)
```
